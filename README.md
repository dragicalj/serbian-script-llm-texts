# Cyrillic and Latin Prompts and LLM-Generated Serbian Texts

## Contents

- `prompts/` – 30 prompts in Cyrillic and Latin
- `texts/` – 360 texts generated by six large language models
  (30 prompts × 2 scripts × 6 models)

Each model folder contains a `cyrillic` and a `latin` folder.
Texts with the same prompt number (e.g. `P01`) form one pair.

The texts were generated on 21 and 22 October 2026.
